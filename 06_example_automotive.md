# Example Audit — Automotive Specialty Services Business

See the full walkthrough in the original EXAMPLE_AUDIT.md at root,
or view online at the project README.

Key lessons from this engagement:
1. "Help me use AI" is not a brief — diagnostic questions come first
2. Voice-first is sometimes the correct architecture, not a workaround
3. Data capture must precede data retrieval
4. Documenting the messy middle is a credibility asset, not a liability
